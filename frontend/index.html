      How this was calculated

      Snapshots fire on: 2-min interval if changed, paste >50 chars, +200 chars vs last, structural edit, source add, or manual. Classification: surface (<20 words), sentence (20–80), structural (>150 words, heading change, or paragraph moved). Hash = SHA-256(prev_hash + timestamp + text) via Web Crypto. Backend re-verifies. Redaction restarts chain and is labeled.

      Background Agent Configuration (Opt-In)

      The background agent is a optional local service that runs on the student's laptop to collect homework data from Schoology/Google Classroom and send summarized reports to parents. This is opt-in only.

      Note: In v1, the agent config is stored on the server, but the actual daemon must be started separately on the student's laptop by running:

      python -m bg_agent.scheduler --cadence weekly
